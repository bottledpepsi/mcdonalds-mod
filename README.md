# McDonald's Mod

> Craft, cook, and eat your way through a full McDonald's menu — with real multi-step recipes, custom effects, and a brand new ore tier.

## What Is This Mod?

McDonald's Mod brings the iconic fast food experience into Minecraft with **genuine crafting depth**. Every menu item has a **multi-step recipe chain**: build tools, prep ingredients, cook them, then assemble the final product.

The mod also introduces **Mcium**, a rare new ore that spawns deep underground and is harder to mine than Netherite. Smelt it into ingots and craft a **full Mcium tool set**.

## Recipe System

Food doesn't just fall out of a crafting table — ingredients need to be prepped first.

- **Fries:** Potato Cutter + potato → 3x Raw Fries → smelt → Fried Potatoes → combine with Paper for Small/Medium/Large
  Fries, or smelt again for a Hashbrown. **The Potato Cutter is used up each time you craft with it.**
- **Nuggets:** raw chicken + wheat → 6x Raw Nuggets → smelt each → McNugget
- **Filet-O-Fish:** wheat + cod/salmon → Raw Filet → smelt → Filet-O-Fish
- **Apple Pie:** wheat + apple + sugar → Raw Apple Pie → smelt → Apple Pie
- **Simple recipes:** Big Mac and McRib are bread-meat-bread sandwiches; McFlurry is milk + sugar + packed ice; Cokes are paper + sugar

## Mcium

A **rare, buried ore** generating deep underground (y=-64 to y=16), harder to mine than Netherite (it needs a
diamond-tier or better pickaxe and takes a long time to break) but with lower tool durability:

| Stat               | Netherite | Mcium    |
|--------------------|-----------|----------|
| Pickaxe durability | 2031      | **1650** |
| Sword damage       | +8        | **+8.5** |
| Mining speed       | 9         | **15**   |
| Enchantability     | 15        | **56**   |

Full tool set (Pickaxe, Sword, Axe, Shovel, Hoe), all fully enchantable.

## Custom mob textures

This mod also replaces the vanilla **Zombie** and **Creeper** textures. If that conflicts with another mod, put a
resource pack above this mod's resources to override `minecraft:textures/entity/zombie/zombie.png` and
`minecraft:textures/entity/creeper/creeper.png`.

## Development

Advancements are generated by `McDonaldsAdvancementProvider`; the generated JSON is committed under
`src/main/generated`. After changing the provider, run `./gradlew runDatagen` and commit the result.

## Compatibility

Minecraft 26.3 · Fabric (Fabric API required) · Java 25+
